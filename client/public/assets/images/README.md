# Branding assets

Place the official logos provided by the project owner here, using these exact file names:

- `uthm-logo.png` — Universiti Tun Hussein Onn Malaysia
- `jtm-logo.png` — Jabatan Teknologi Maklumat
- `pusat-pengajian-diploma-logo.png` — Pusat Pengajian Diploma

The application tries the `.png` file first and falls back to the clearly labelled
`.svg` placeholder when the PNG is missing. Do not generate or invent logos.
Use of official marks must be authorised by the institution.
